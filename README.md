# Coin to Fish - MVP

MVP web de jogo idle com:

- Login/registro simples por username + email
- Peixe inicial + aquário básico
- Produção passiva por minuto (incluindo cálculo offline no login/dashboard)
- Consumo de energia do peixe
- Item `Comida Simples` para recuperar 50% da energia
- Upgrades de peixe e aquário
- Missões básicas de onboarding

## Executar

```bash
npm install
npm start
```

Acesse `http://localhost:3000`.

## Testes

```bash
npm test
```
